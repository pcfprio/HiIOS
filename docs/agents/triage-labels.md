# Triage 标签映射

各工程技能围绕五个标准 Triage 角色展开协作。本文件将这些标准角色映射为本仓库 Issue 追踪器实际使用的标签名称。

| `mattpocock/skills` 标准角色 | 本仓库标签名称    | 含义说明                         |
| ---------------------------- | ----------------- | -------------------------------- |
| `needs-triage`               | `needs-triage`    | 需要维护者评估此 Issue           |
| `needs-info`                 | `needs-info`      | 等待提交者补充更多信息           |
| `ready-for-agent`            | `ready-for-agent` | 规格已明确，可交由后台智能体实现 |
| `ready-for-human`            | `ready-for-human` | 需要人工实现                     |
| `wontfix`                    | `wontfix`         | 不予处理                         |

当技能提及某个分流角色（例如“添加可交由智能体处理的 Triage 标签”）时，使用上表“本仓库标签名称”列对应的标签字符串。

如需调整本仓库实际使用的标签命名，直接修改“本仓库标签名称”列即可。
